# Nexora Markets — Midnight Obsidian 3D

React 19 + Vite responsive English-language dashboard concept for Nexora Markets.

## Run

```bash
npm install
npm run dev
```

Local address: `http://localhost:3080`.

```bash
npm run build
npm run preview
```

**Important:** This is a frontend preview only. The BNB Chain smart contract is not deployed, wallet transactions are disabled and daily percentage tiers are conditional hypothetical caps, not guaranteed returns. No real balances or executed trading results are shown.

The latest model shows conditional tiers of 1%, 1.25%, 1.5%, 2%, 2.5% and 3-level referral percentages of 15%, 7%, 3% of settled profit. The UI includes a sample rank calculator; it does not verify real 24-hour funding, unique account identity, branch balance or profit availability.
